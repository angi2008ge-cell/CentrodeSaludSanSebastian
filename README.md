# Centro de Salud San Sebastián
Sistema de gestión de pacientes y citas médicas desarrollado en Java NetBeans.

- **Patrones de Diseño:** Factory (`CitaFactory`) y Singleton (`AlmacenSeguroSingleton`).
- **Seguridad:** Enmascaramiento de DNI según Ley N.° 29733.
- **Funciones:** Búsqueda y filtrado de citas con Java Streams.
